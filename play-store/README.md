# Airlock Play Store Listing

Upload-ready assets and copy for the default English (United States) listing.

## Console Values

- App name: `Airlock`
- Category: `Productivity`
- Short description: see `listing-copy.txt`
- Full description: see `listing-copy.txt`
- App icon: `app-icon-512.png`
- Feature graphic: `feature-graphic-1024x500.png`
- Phone screenshots: upload `screenshots/01-...` through `04-...` in order

The screenshots are 1080 x 1920 PNG files. The feature graphic is 1024 x 500
and the store icon is 512 x 512. Keep these listing claims synchronized with
`docs/PLAY_CONSOLE_SUBMISSION.md` and the shipped app.
